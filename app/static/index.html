如何获取豆瓣 Cookie？
  1. 在浏览器中登录 豆瓣电影。
  2. 按 F12 打开开发者工具 → Network（网络），刷新页面。
  3. 选中 movie.douban.com 的页面请求，在 Request Headers 中复制完整 Cookie。
  4. 粘贴到上方，至少需要 dbcl2 和 ck，点击“验证并保存 Cookie”。

如果遇到安全验证，请先在与服务相同出口网络的浏览器中完成验证，再重新导入。
